# Agent roles

See [roles and skills](role-skill-matrix.md) for the current responsibilities.
The [delivery model](07-delivery-model.md) defines the resumable task contract,
review and merge rules.

Use the smallest team that advances independent work. A Lead may implement as
the named write-owner; reviewers remain independent and read-only. Multiple
developers use isolated worktrees and distinct surfaces. Program coordination
is reserved for multiple related batches.

Model choice follows complexity and uncertainty, while review and approvals
follow actual risk and authority. A model tier never grants an external action.

Return concise evidence: exact SHA, findings and their reproduction, actual
checks, unrun checks, residual risk and next action. Follow project severity
criteria and avoid repeated review of unchanged code without new evidence.

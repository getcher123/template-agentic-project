# Optional skills module

Apply AGENTS.md and start with the task. Use capability-router only when routing
is useful; select procedures from docs/skills-registry.md. It is a menu.

Reuse approved issue/handoff plans and refresh only changed checkpoint, scope
or authority. One bounded task can have one Lead/Implementer. Use isolated
worktrees for parallel code changes and program-orchestrator only for related
batches. Reviewers default read-only and report exact SHA plus evidence.

Local checks match the diff. Required CI and human review remain mandatory.
The PR body uses .github/pull_request_template.md as its only template.
No repeated review of unchanged SHA without new evidence.

External tools provide access, not authority. Keep project scopes, user
configuration and credentials separate. This snippet grants no permissions.

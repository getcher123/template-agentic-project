# Новый проект: быстрый запуск

1. Создай репозиторий и включи git.
2. Установи `recommended` профиль.
3. Замени placeholders: `<PROJECT_NAME>`, `<REPO_NAME>`, `<ORG_OR_USER>`, `<DEFAULT_BRANCH>`, `<PRIMARY_OWNER>`.
4. Настрой реальные команды в `Makefile`.
5. Заполни `docs/00..08`.
6. Создай GitHub Project и labels, если используешь GitHub.
7. Создай первый маленький issue с acceptance criteria.
8. Только после этого запускай Codex на реализацию.

Главное правило:

```text
Сначала issue и scope.
Потом агент.
Потом PR и review.
```

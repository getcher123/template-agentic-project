# AGENTS.md: русская справка

Английский `core/AGENTS.md` — основной контракт. Эта справка фиксирует его
ключевые правила.

- Начинайте с задачи и используйте `docs/START_HERE.md` только как указатель.
- Issue/handoff — единая возобновляемая карточка работы; повторно проверяются
  только SHA, scope, полномочия и другие изменившиеся факты.
- Одна worktree имеет одного write-owner. Один Lead может быть Implementer.
- Параллельные разработчики работают в разных worktree с разными поверхностями.
- Program Orchestrator применяется к нескольким связанным батчам.
- Локальные проверки соответствуют diff; обязательный CI проверяет финальный SHA.
- Агентское заключение не является человеческим или CODEOWNERS approval.
- Не повторяйте ревью неизменившегося commit без новых данных.
- Доступ инструмента не даёт разрешения. Полномочия одного проекта нельзя
  переносить в другой.
- Не читайте, не копируйте и не публикуйте секреты; не меняйте пользовательские
  `.env` и настройки агента.
- Финальный handoff содержит результат, полный SHA, проверки, риски, rollback
  и следующий шаг. Merge выполняется только по правилам целевого проекта.

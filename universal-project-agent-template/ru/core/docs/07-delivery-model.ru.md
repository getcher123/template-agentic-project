# Delivery model

## Принципы

- GitHub Issues — контракт задачи.
- GitHub Project — статус поставки.
- Один issue соответствует одной branch, одной worktree и одному PR.
- Delivery Planner / Backlog Architect ведёт decomposition, backlog, GitHub Issues/Projects metadata, priority, size, risk и dependencies.
- Agent-ready issue должен иметь objective, context, acceptance criteria, allowed scope, forbidden scope и validation commands.
